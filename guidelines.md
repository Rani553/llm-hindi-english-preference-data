# Comparison guidelines

For each prompt you see two responses (order is shuffled, so you don't know which model wrote which).

## Score each response 1–5 on
| Dimension | 5 = | 1 = |
|---|---|---|
| Correctness | Every fact/step is right | Contains a clear error |
| Helpfulness | Fully solves what was asked | Misses the point |
| Clarity | Easy to follow, well organized | Confusing or padded |
| Language fit | Same language/script/tone the user used | Wrong language or tone |

## Then pick the overall winner: 1, 2, or tie
- Correctness beats style: a shorter correct answer wins over a longer one with an error.
- Safety issues (wrong medical/financial advice) lose automatically.
- Use **tie** only when you honestly can't choose.
- Write one sentence: *why* the winner is better.
